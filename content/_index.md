BeamFoundry is the home of **Rays**, an ecosystem designed to bring powerful Inversion of Control (IoC), dependency injection, and object-oriented design patterns to modern Go applications without sacrificing the performance and simplicity Go is known for.

## 🤝 Open Source

All BeamFoundry projects are proudly open-source and built for the Go community. We welcome contributions, issues, and feature requests. 

Check out our organization on GitHub to explore the code, report issues, or submit pull requests!

* 🏢 **[BeamFoundry GitHub Organization](https://github.com/BeamFoundry)**
